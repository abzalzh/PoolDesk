# Changelog

## 1.0.0 — 2026-11-25

First release in the public 1.x version line. Earlier 2.x packages were development prototypes.

- .NET 8 self-contained Windows x64 app, solution/project files and installer.
- Fixed conflicting native frame; dark custom title bar, thin grid scrollbar, DPI-aware text.
- RU/EN UI, themes, settings and completion/error sounds.
- Modded and base star ratings, map metadata and unresolved-slot links.
- Game folder detection, remembered choice, local map index and MD5-aware skips.
- Three parallel downloads by default, mirror fallback, retries, pause/resume and cancellation.
- Per-install logs, diagnostics, history and ownership-aware rollback.
- Atomic collection writes, rotating backups, running-game guard and conflict detection.
- Offline regression suite, CI, SHA-256 checksums, issue templates and licensing notices.
