# PoolDesk 1.0 — проверка сборки

Дата: 25 ноября 2026 года.

- Финальные исходники: 22 автономных теста пройдены. Запуск и полный вывод сохранены при сборке.
- Проверены: чтение/запись коллекций с Unicode, пустые коллекции, повреждённые и усечённые файлы, атомарность при ошибке, защита от параллельного изменения, ротация бэкапов, блокирующий guard игры, настройки, Songs/.osz индекс, MD5, моды и нативный расчёт, фикстура API, fallback, докачка Range/ETag и ответ 200, пауза/отмена, небезопасные пути архива, продолжение после ошибки, пропуск установленных карт, передача владения общими картами, удаление пула, сохранение изменённых файлов, лимит параллельности, RU/EN/light UI и resize hit tests.
- `dotnet publish`: self-contained win-x64 EXE, без предупреждений компилятора.
- Готовый single-file EXE запущен в обычной Windows. Через настоящий интерфейс загружен турнир 73, показаны карты и рассчитаны NM/HD/HR звёзды — нативная библиотека найдена внутри сборки. Системной белой рамки на осмотренном окне нет.
- Проверен настоящий API osu!Collector и ZIP с пятью сложностями через Sayobot. Nerinyan для тестового набора вернул not_found; доступность каждого зеркала не гарантируется.
- Установщик собран Inno Setup 6.7.4. Выполнена установка в отдельную тестовую папку, SHA-256 установленного EXE совпал с portable. Тестовая установка удалена штатным uninstaller.
- Реальная папка Songs пользователя и его collection.db не изменялись. Тесты коллекций используют синтетические данные; образец настоящего пользовательского collection.db для round-trip в этой среде не был доступен.

Ограничения проверки: не проверено на всех версиях Windows/DPI и на чистой машине без VC++ Runtime. Ветка установки Microsoft Runtime собрана, но повторная установка системного Runtime не выполнялась. GitHub Actions подготовлен, но его серверный запуск произойдёт после загрузки репозитория. Цифровая подпись не добавлена: сертификата издателя нет. Недоступность карт и серверов остаётся внешним ограничением.
